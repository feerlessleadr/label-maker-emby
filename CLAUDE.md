- Trap: never edit a source file with `perl -0pi -e 's|...|...|'` when the pattern or replacement contains a `|` (for example `||` in JavaScript or a PowerShell pipe): the `|` splits the expression and the replacement text gets pasted at the top of the file. Use the Edit tool, or a different delimiter, and check the result.
