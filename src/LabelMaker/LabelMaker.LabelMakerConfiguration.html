Lanes

A lane is one inbox folder (where downloads arrive) and the library folder its albums are filed into. Deleting a lane never touches any file. Use full paths: a drive letter such as E:\Downloads\Music or a network path such as \\server\share. A network path is the safer choice when Emby runs as a service. Two lanes cannot share an inbox, and an inbox cannot be inside a library folder.

Matching

How sure Label Maker has to be before it files an album without asking. The defaults were measured on a real library of 287 albums, where nearly every album filed by itself was the right one.
A match scores 1.00 when every file fits perfectly. Lower this and more albums are filed without you; raise it and more wait for review.
Below this Label Maker says it found no match.
One file that fits no track poorly keeps the whole album out of automatic filing.

Naming and tags

By default files are named exactly the way MusicBrainz Picard's stock script names them (Artist/Album/01 Title).
Supports the parts of Picard's scripting that file naming needs: $if, $if2, $and, $or, $gt, $num and the usual %variables%.
Picard writes one by default. Other tags in the files, such as lyrics, ratings and ReplayGain, are never touched.
