## Label Maker 0.1.1.0 (first trial release)

An Emby Server plugin that matches downloaded albums on MusicBrainz, tags them, names them with Picard's stock script, and files them into the right library folder. **This is a trial build: it starts in dry run** (it shows what it would do and moves nothing by itself). See `docs/INSTALL-TRIAL.md` before turning dry run off.

### Install
- With the GitHub Repo Plugin Install plugin: install `LabelMaker.dll` from this release, then restart Emby.
- Or copy `LabelMaker.dll` into Emby's `plugins` folder and restart Emby.
- After about a minute **Label Maker** appears under **Advanced** in the dashboard. Add a lane under Settings > Lanes, then run **Dashboard > Check the folders**.

### What is in it
- Lanes (an inbox and its library folder), checked every minute; an album is handled once its files stop changing.
- Matching against MusicBrainz with a track-by-track check; single tracks and partial albums work; albums that are not certain go to a review list with a plain sentence saying why.
- Review on the plugin page: preview what an edition would do, pick another edition, search by artist and album, paste a MusicBrainz link, say which track a file is, keep your own tags, skip, split a folder that holds several albums, discard (to a `_Trash` folder, nothing is deleted), and undo.
- A folder health check (read, create, rename, delete, free space, path length) and lane rules.
- Phone alerts to the Embidextrous app over Emby (no outside service), with a catch-up list and a catalog the app can read. Contract: `docs/NOTIFICATIONS.md`; routes: `docs/API.md`.

### How it was tested
284 unit tests, and 35 live checks on an Emby 4.10 test server with real tagged files, the real MusicBrainz and an administrator websocket. On a real library of 287 albums with known answers, at the default settings 82% of full albums were filed automatically with 98% of those on the right album, and 86% of single tracks with 99% on the right album (`docs/CALIBRATION.md`). Anything less certain waits for you.

### Known limits
- Not tried yet on a production server with network shares; the folder health check tells you what to fix.
- Cover art is not downloaded (a `cover.jpg` that comes with a download is moved with it).
- An album that is already in the library is shown as "Already in library" with no keep-both or replace choice yet.
- Classical music and audiobooks are not recognized specially; they go to review like any album that does not fit.
- The phone app does not read the alerts yet (the app is built separately).

### Verify the download
`LabelMaker.dll.sha256` has the SHA-256. The file also carries a signed build attestation: `gh attestation verify LabelMaker.dll --repo feerlessleadr/label-maker-emby`.
