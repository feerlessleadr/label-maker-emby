## Label Maker 0.1.4.0 (folder picker)

### What is new
- **Browse button for lane folders.** On Settings > Lanes, the inbox and library boxes now have a **Browse...** button that opens Emby's own folder picker on the server's file system (drives and network shares), the same dialog Emby uses when you add a library. Pick a folder and its full path is filled in; no copy and paste. The picker also checks that the folder can be written to. Typing a path still works.
- **No example paths.** The boxes no longer suggest paths that belonged to a particular setup, and the help text, messages and documents use neutral examples.

### Still true
This is a trial build that **starts in dry run**: it matches albums and shows what it would do, and moves nothing by itself. Install and first steps: `docs/INSTALL-TRIAL.md`. If you installed 0.1.1.0, its page did not open; 0.1.3.0 and this version fix that.

### How it was tested
284 unit tests; 37 live checks on a private, throw-away Emby 4.10 instance (including the served page script loaded in a real browser); and the page opened by clicking **Label Maker** in the dashboard sidebar, with the new Browse button used by hand in a browser (opening the picker, choosing a folder, and seeing the path filled in), plus every tab and action. The published file was tested the same way after the release was built.

### Known limits
Unchanged: not yet tried on a production server with network shares (the folder health check tells you what to fix), no cover art download, no keep-both or replace choice for an album already in the library, no special handling of classical music or audiobooks, and the phone app does not read the alerts yet.

### Verify the download
`LabelMaker.dll.sha256` has the SHA-256. The file also carries a signed build attestation: `gh attestation verify LabelMaker.dll --repo feerlessleadr/label-maker-emby`.
