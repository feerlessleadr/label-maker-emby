## Label Maker 0.1.3.0 (fixes the page that would not open)

**If you installed 0.1.1.0, please update.** In 0.1.1.0 the settings page did not open: clicking Label Maker under Advanced did nothing, because the page's script had a syntax error. This version fixes it. Nothing else about how Label Maker matches and files albums changed.

### What is fixed
- The page opens. The script is now checked by a real browser before every release (and by the live test against the exact file the plugin serves, and by CI).
- On the Settings page, a value the server refuses now shows the server's own sentence (for example "The automatic threshold must be between 0.50 and 1.00 and at least the review threshold."), and the "Saved" note stays visible after a good save.
- On an album, if you start a search and a pasted-link lookup close together, a late answer no longer replaces a newer one.
- The Open button on the Albums list no longer wraps in a narrow column.

### Still true from 0.1.1.0
This is a trial build that **starts in dry run**: it matches albums and shows what it would do, and moves nothing by itself. Your own choices on the Albums tab are still carried out. Install and first steps: `docs/INSTALL-TRIAL.md`. Phone alerts: `docs/NOTIFICATIONS.md`. Routes: `docs/API.md`.

### How it was tested
284 unit tests; 36 live checks on an Emby 4.10 test server (real tagged files, real MusicBrainz, an administrator websocket, and the served page script loaded in a real browser); and the page opened by clicking **Label Maker** in the dashboard sidebar, then every tab and action used by hand in a browser: Dashboard buttons, health check, Albums list, review panel, search, pasted link, preview, filing, keep my tags, split by album, undo, and the Settings page including saving, a refused value and adding and removing a lane. The published file was tested the same way after the release was built.

### Known limits
Unchanged from 0.1.1.0: not yet tried on a production server with network shares (the folder health check tells you what to fix), no cover art download, no keep-both or replace choice for an album already in the library, no special handling of classical music or audiobooks, and the phone app does not read the alerts yet.

### Verify the download
`LabelMaker.dll.sha256` has the SHA-256. The file also carries a signed build attestation: `gh attestation verify LabelMaker.dll --repo feerlessleadr/label-maker-emby`.
