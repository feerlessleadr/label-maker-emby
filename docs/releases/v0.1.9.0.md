## Label Maker 0.1.9.0 (song-title search, and "file only the new files")

### What is new
- **When the album name leads nowhere, Label Maker searches for the song titles.** If the album name in the tags is wrong, missing or "Unknown Album" and no album-name search finds an album that fits, Label Maker now asks MusicBrainz for up to three of the song titles with their artist, sees which albums hold those songs, and checks them track by track like any other album. An album found this way **always goes to your review list** with the sentence "Found by searching for the song titles, because the album name in the tags led nowhere, so please check it." It is never filed by itself. The Albums tab's **Search** button does the same when what you typed fits nothing. On 40 albums of your real library with the album name removed, all 40 reached the review list (none "No match"), and the right album was the top suggestion for 30. The 10 others were single songs, which can sit on dozens of albums. Rules: `docs/MATCHING-RULES.md` section 8g.
- **File only the new files of a partly overlapping album.** If the library already has some of an album's tracks (for example tracks 1 to 3, and a download brings tracks 2 to 4), the preview of an *Already in library* album now offers a third choice next to Keep both and Replace: **File only the new files (set the others aside)**. The new files are filed. The files the library already has are not touched; your copies are set aside in the inbox's `_Duplicates` folder (nothing is deleted). **Undo** puts everything back. Rules: section 8h.
- Nothing else changed: thresholds, the edition rule and automatic filing work as before.

### Still true
This is a trial build that **starts in dry run**. Install and first steps: `docs/INSTALL-TRIAL.md`.

### How it was tested
341 unit tests (eight new for the song-title search, including a recorded real MusicBrainz answer, and eight new for the skip choice); the live test (62 checks, five new, the song-title ones against the real MusicBrainz) on a private, throw-away Emby 4.10 instance; the new choice and the song-title review result used by hand in a browser. **Not yet seen:** these on your own server and library.

### Known limits
A single song that is on many albums often cannot be matched to the right one by its title alone (it is shown for you to pick). No special handling of classical music or audiobooks, no cover art embedded in the tags.

### Verify the download
`LabelMaker.dll.sha256` has the SHA-256. The file also carries a signed build attestation: `gh attestation verify LabelMaker.dll --repo feerlessleadr/label-maker-emby`
