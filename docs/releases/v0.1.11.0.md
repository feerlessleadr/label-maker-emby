## Label Maker 0.1.11.0 (a live status channel for the phone app)

### What is new
- **A live status channel for the Embidextrous app's Library tab.** The app can now subscribe over Emby's own websocket and receive Label Maker's status without polling: right after subscribing, within about a second of every change, and as a heartbeat every 30 seconds. It works like the alert subscription from 0.1.5.0: only an administrator can subscribe, the token travels only inside the websocket and is never logged, and the status carries no folder path. `Info` lists `"statuspush"` so the app can tell the plugin has it. The contract for the app is `docs/NOTIFICATIONS.md` section 13. **You will not see any difference on the plugin's page**; the app side has to be built to use it.
- **Fixed: the status did not notice a Pause, a dry-run switch, a lane change or MusicBrainz trouble.** The status `Version` is meant to grow with every change, but it only counted albums and alerts. It now also grows when pause, dry run, the lane list or MusicBrainz's health changes, so anything that compares `Version` (the app, or a script) sees them.
- Nothing else changed: matching, filing, cover art, duplicate choices, the song-title search and the review of classical music, audiobooks and podcasts work as before. The settings page is the same as in 0.1.9.0.

### Still true
This is a trial build that **starts in dry run**. Install and first steps: `docs/INSTALL-TRIAL.md`.

### How it was tested
363 unit tests (ten new: when the status is sent, the heartbeat, who may subscribe, the token parsing, and the version growing on each kind of change); the live test (70 checks, eight new) on a private, throw-away Emby 4.10 instance with sockets that connect the way the app does: the status arrives on subscribing, a Pause pushes a new status within seconds, the heartbeat arrives, no folder path appears, and a regular user, an unknown token and a missing token are each refused. **Not yet seen:** the app using it (the Android side is separate work).

### Known limits
A long DJ mix is held for review (a file over 90 minutes). A single song that is on many albums often cannot be matched to the right one by its title alone. No cover art embedded in the tags.

### Verify the download
`LabelMaker.dll.sha256` has the SHA-256. The file also carries a signed build attestation: `gh attestation verify LabelMaker.dll --repo feerlessleadr/label-maker-emby`
